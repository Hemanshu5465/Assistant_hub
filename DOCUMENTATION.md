# AI Assistant Hub - Project Documentation

**AI Assistant Hub** is a "Personal Intelligence Ecosystem" designed to provide users with specialized AI agents for various aspects of life, including coding, health, finance, and productivity.

## 🌟 Features

- **Specialized AI Agents**: Dedicated assistants for specific domains (Coding, Health, Finance, Travel, etc.).
- **Interactive Chat Interface**: Real-time chat with history preservation.
- **User Authentication**: Secure Login and Registration system using JWT and Bcrypt.
- **Responsive Design**: Modern, glassmorphism-inspired UI with smooth animations.
- **Sparkle Effects**: Custom visual effects on the landing page.
- **Admin Dashboard**: (In structure) Admin functionalities for managing the hub.
- **Contact Form**: Functional contact form with backend integration.

## 🛠️ Technology Stack

### Frontend
- **Languages**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with animations (`style.css`, `notifications.css`)
- **Assets**: Custom icons and images

### Backend
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB (via Mongoose)
- **Authentication**: `jsonwebtoken`, `bcrypt`
- **AI Integration**:
    - Google Generative AI (Gemini)
    - OpenAI API
    - Groq SDK

## 🚀 Setup & Installation

### Prerequisites
- Node.js installed
- MongoDB installed and running (or a MongoDB Atlas URI)

### Backend Setup
1.  Navigate to the backend directory:
    ```bash
    cd backend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Configure Environment Variables:
    - Create a `.env` file in the `backend/` folder.
    - Add the following keys:
      ```env
      PORT=5000
      MONGO_URI=your_mongodb_connection_string
      JWT_SECRET=your_jwt_secret
      GEMINI_API_KEY=your_gemini_key
      OPENAI_API_KEY=your_openai_key
      GROQ_API_KEY=your_groq_key
      ```
4.  Start the Server:
    ```bash
    npm start
    ```
    The server will run on `http://localhost:5000`.

### Frontend Setup
1.  Open `index.html` in your browser or use a live server extension (vs-code) to serve the root directory.
2.  Ensure the frontend `fetch` calls in `script.js` and `chat.js` point to `http://localhost:5000` (or your configured backend URL).

## 💡 Usage

1.  **Home**: Explore the different assistants.
2.  **Register/Login**: Create an account to save your chat history.
3.  **Chat**: Click on an assistant card to enter the `chat.html` interface.
4.  **Profile**: Manage your user settings in `forms/profile.html`.
